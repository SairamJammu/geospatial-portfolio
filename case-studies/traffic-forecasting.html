Overview

Forecasting traffic speeds with spatial context.

The project uses the METR-LA traffic sensor dataset to forecast highway speed patterns across a sensor network. The applied goal is to support congestion analysis, urban mobility planning, and map-based transportation intelligence.

01

Problem Statement

  • Traffic forecasting is spatial as well as temporal.
  • Models should account for connected road sensors, not isolated time series only.
  • Outputs should be readable for planning and operational review.
02

Dataset

  • METR-LA traffic speeds from 207 Los Angeles highway sensors.
  • 5-minute speed readings from March to June 2012.
  • Adjacency matrix, weather features, and road context for model experiments.
03

Methodology

  • Clean missing sensor values and create chronological train/validation/test splits.
  • Build 60-minute history windows to predict 15, 30, and 60 minute horizons.
  • Compare temporal baselines with Graph WaveNet-style spatial modeling.
04

Tools Used

  • Python, PyTorch, pandas, NumPy, scikit-learn, Matplotlib, Plotly.
  • Graph modeling concepts, time-series forecasting, and evaluation metrics.
  • GIS-style map visualization and dashboard prototype planning.

Results

Model outputs and decision value.

Evaluation

The project compares MAE, RMSE, and MAPE across forecast horizons. The strongest Graph WaveNet variant reports approximately 3.53 MAE at the 60-minute horizon with MAPE near 9.88%.

The main result is not just a score: the project shows how traffic sensors, road-network structure, and weather/road features can be combined into a more practical urban analytics workflow.

Practical Use Case

A transportation analyst or planning team could use this type of workflow to compare expected congestion patterns across corridors, identify high-variance sensors, and evaluate where operational monitoring or infrastructure review may be needed.

Limitations

Current Constraints

The current work is strongest as a research-style prototype. The next improvement is turning the notebook workflow into a small app with clearer dashboard interactions, sensor-level drilldowns, and reproducible data refresh steps.

Future Improvements

Next Build Steps

Planned improvements include a Streamlit or Folium dashboard, cleaner API-style preprocessing, map-based sensor selection, explainable model comparisons, and additional urban context features.
